# CMC 离线补充实验

运行环境：Python 3.12、NumPy 1.26.4、Pydantic 2.12.4。解压后在实验包根目录运行：

```powershell
python tests/test_cmc_revision_20261106.py
python scripts/cmc_revision_20261106.py
```

不调用模型服务。脚本读取归档及脱敏审计，输出到 `research_artifacts/cmc-revision-20261106`；建议在副本中复现。毫秒字段取决于机器，非计时结果可精确比较。原始任务与目录不覆盖。

- `runs.csv`：历史配额重放、独立固定配额及类型异质实例的逐次结果，共 23,376 行。
- `ordering.csv`：380 个历史可行任务各用规范顺序与五个种子重排，共 2,280 行。
- `benchmark.json`：24 个类型分族实例及 24 个接口断开实例的完整定义和独立枚举解数。
- `summary.json`：按场景、任务类型、配额和方法汇总；至少一解以任务多数表决，候选召回和解集保留在全目录可行的任务重复上计算。
- `audit.json`：首次保留请求、阶段尝试及最终执行的不同分母；不包含原始响应或私人请求标识。
- `input_manifest.json`：输入哈希和运行种子。固定配额按角色分别新增 1、3、6 个候选，保留初始候选；不等同于历史模型按独立配额重新生成。

新类型用例仅是合成代理。没有新增可核验模型调用、学习式检索、真实装配验证或完整 token/费用计量。
