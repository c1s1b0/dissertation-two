# 检索与扩展任务实验

本目录保存 48 个新任务的冻结输入、96 次本地 Qwen3-8B 阶段响应、BM25/E5 检索分数及 KTR 目录案例。已运行的 24 个本地任务和 400 个历史任务分别保留其身份。历史检索对照沿用归档实际配额，新任务采用独立固定配额。历史结果不能归因于本地权重。

## 离线重放

先复制一份本目录作为重放输出位置。从实验包根目录分别运行以下命令。两条命令读取已存档的响应和分数，无需联网、生成模型权重或稠密检索模型权重。

```powershell
python scripts/cmc_retrieval_extension_20261109.py --output replay-extension
python scripts/cmc_retrieval_extension_20261109.py --output replay-extension --historical
```

- `inputs.json`、`protocol.json` 和 `trials.jsonl` 记录新任务、模型摘要、首轮提示词和两阶段响应。
- `retrieval_scores.json` 和 `historical_scores.json` 记录各角色的查询、候选文本和分数。E5 模型修订与权重摘要见 `e5_manifest.json`。若需从本地权重重算检索，加用 `--e5` 指向经核验的模型文件目录。
- `summary.json` 和 `metrics.json` 是新任务的统计与逐任务验证。历史检索对应两个 `historical_retrieval_*.json`。
- `ktr_case.json` 记录 KTR 目录印刷第 34 页的来源、数值、构造的筛选输入和结果。联合可行性由全枚举和按规格取交集独立核对。

案例只验证目录中的标称扭矩、孔径范围和规格一致性，不能用作选型批准或装配验收。
